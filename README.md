A cloud-based file storage application that allows users to securely upload, manage and share their files.

**Key Features**
- 🔐 User authentication
- ☁️ Cloud file uploads
- 📁 File management and downloads
- 🔗 Temporary file-sharing links
- 🛡️ Private storage with Row Level Security

**Tech Stack:** React · TypeScript · Supabase · PostgreSQL · Supabase Storage

### 💼 HireLens — AI-Powered Talent & Career Platform

A role-based career platform connecting job seekers and recruiters.

**Key Features**

- 🔐 Firebase Authentication
- 💼 Job posting and discovery
- 📄 Application management
- 🤖 AI Career Advisor
- ✍️ AI Cover Letter Generator
- 🛡️ Admin dashboard

**Tech Stack:** React · Firebase · Google Gemini AI
